# Step 2 - Problem Approach Thinking

## 1. Valid Anagram

Ask yourself:

* Do I care about order? → No
* What matters? → frequency

Conclusion:

> Build counts → compare

---

## 2. Group Anagrams

Ask:

* How do I know two strings belong together?
* Can I convert them into same representation?

Conclusion:

> Transform → use as key → group

---

## 3. First Unique Character

Ask:

* Do I need frequency? → Yes
* Do I need order? → Yes

Conclusion:

> Count first → scan again
