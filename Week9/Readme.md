# WEEK 9 - Graphs (BFS + DFS)

## Weekly Goal

By the end of this week, you should be able to:

* Represent graphs using adjacency list/matrix
* Solve traversal problems using DFS
* Solve traversal problems using BFS
* Detect cycles in graphs
* Solve matrix-as-graph problems
* Understand dependency graph problems
