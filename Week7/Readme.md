# 🌳 WEEK 7 - TREES BASICS (DAY-BY-DAY ROADMAP)

## 🎯 Weekly Goal

Build strong intuition for trees and recursion using DFS. By the end of this week, you should be able to:

* Understand tree structure
* Apply recursive DFS
* Solve basic tree problems confidently

---

# 📅 DAY 1 - Tree Fundamentals

## Goals

* Understand what a tree is
* Learn binary tree structure

## Topics

* Tree terminology (root, leaf, height)
* Binary tree structure
* Recursive nature of trees

## Practice

* Create TreeNode class
* Manually build a small tree

## Outcome

You understand how trees are formed and stored

---

# 📅 DAY 2 - DFS Traversals (Core Day)

## Goals

* Learn Depth First Search

## Topics

* Inorder (LNR)
* Preorder (NLR)
* Postorder (LRN)

## Practice

* Implement all 3 traversals
* Dry run on sample tree

## Outcome

You can traverse any tree using recursion

---

# 📅 DAY 3 - Problem Solving (Easy)

## Problems

* Max Depth of Binary Tree
* Same Tree

## Focus

* Base case handling
* Recursive return values

## Outcome

You understand how recursion builds answers

---

# 📅 DAY 4 - Inorder Traversal (LeetCode Style)

## Goals

* Return results instead of printing

## Topics

* Using helper DFS function
* Storing results in list

## Practice

* Solve inorder traversal problem

## Outcome

You can convert recursion into usable output

---

# 📅 DAY 5 - Revision + Memory Training

## Tasks

* Rewrite all code without seeing
* Explain logic out loud
* Dry run manually

## Outcome

Strong retention and clarity

---

# 📅 DAY 6 - Mixed Practice

## Practice Problems

* Max Depth (redo)
* Same Tree (redo)
* Inorder Traversal (redo)
* One extra tree problem

## Outcome

Confidence in solving tree basics

---

# 📅 DAY 7 - Mock Test

## Rules

* 45–60 minutes
* No help
* No notes

## Problems

* Max Depth
* Same Tree
* Inorder Traversal

## Outcome

Interview readiness check

---

# 🧠 CORE PATTERN (IMPORTANT)

Every tree problem follows:

1. Base Case
2. Solve Left
3. Solve Right
4. Combine Result

---

# ⚠️ COMMON MISTAKES

* Forgetting base case
* Mixing traversal order
* Not returning values
* Confusing None with node
