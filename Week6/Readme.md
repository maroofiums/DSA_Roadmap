# WEEK 6 - BINARY SEARCH ROADMAP 

## Overview

This week focuses on mastering Binary Search patterns from fundamentals to advanced interview-level problems.

You will learn:

* Standard Binary Search
* Edge case handling
* Rotated arrays
* Boundary search (first/last occurrence)
* Peak finding
* Binary Search on Answer (optimization problems)

---

# DAY 1 - Foundations of Binary Search

## Goal

Understand how binary search works and implement it from scratch.

## Concepts

* Search space reduction (O(log n))
* Sorted array requirement
* mid, left, right logic
* while condition (<= vs <)

## Practice Problems

1. 704. Binary Search (Easy)
2. 35. Search Insert Position (Easy)

## Outcome

* You can write binary search without looking at code

---

# DAY 2 - Implementation Mastery & Edge Cases

## Goal

Fix common binary search bugs and understand edge cases.

## Concepts

* Off-by-one errors
* Infinite loop issues
* Correct pointer movement
* Mid calculation safety

## Practice Problems

1. 69. Sqrt(x) (Easy)
2. 374. Guess Number Higher or Lower (Easy)

## Outcome

* You can debug broken binary search implementations

---

# DAY 3 - Rotated Sorted Array Pattern

## Goal

Solve binary search problems in rotated arrays.

## Concepts

* One half is always sorted
* Identify sorted side using mid
* Decide search direction

## Practice Problems

1. 33. Search in Rotated Sorted Array (Medium)
2. 81. Search in Rotated Sorted Array II (Medium)

## Outcome

* You can handle modified sorted arrays confidently

---

# DAY 4 - Boundary Search (First/Last Occurrence)

## Goal

Master first/last position and boundary problems.

## Concepts

* Lower bound logic
* Upper bound logic
* First true / last true pattern

## Practice Problems

1. 278. First Bad Version (Easy)
2. 34. Find First and Last Position of Element in Sorted Array (Medium)

## Outcome

* You can solve boundary-based binary search problems

---

# DAY 5 - Peak & Mountain Problems

## Goal

Learn binary search on non-sorted structures.

## Concepts

* Increasing vs decreasing slope
* Peak finding logic
* Shape-based binary search

## Practice Problems

1. 162. Find Peak Element (Medium)
2. 852. Peak Index in a Mountain Array (Easy)

## Outcome

* You can apply binary search beyond sorted arrays

---

# DAY 6 - Binary Search on Answer (IMPORTANT)

## Goal

Use binary search for optimization problems.

## Concepts

* Search space is answer range
* Monotonic condition
* Minimum / maximum optimization problems

## Practice Problems

1. 875. Koko Eating Bananas (Medium)
2. 1011. Capacity To Ship Packages Within D Days (Medium)

## Outcome

* You can solve real-world optimization problems

By the end of this week, you should be able to:
